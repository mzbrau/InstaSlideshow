# Getting Started

This guide walks you through everything you need to get InstaSlideshow running on your machine.

---

## Prerequisites

| Requirement | Minimum version |
|---|---|
| Windows OS | Windows 7 SP1 or later |
| .NET Framework | 4.8 |
| Instagram account | A valid Instagram username and password |
| Privileges | Administrator rights are required only when running from a protected directory (e.g. `C:\Program Files\`) |

:::caution Administrator rights
InstaSlideshow saves a session file (`state.bin`) beside the executable. When installed under `C:\Program Files\`, Administrator privileges are required to write this file. Source builds to a user-writable folder do not need elevation.
:::

---

## Installation

### Option A — pre-built installer (recommended)

1. Download the latest installer from the [GitHub Releases page](https://github.com/mzbrau/InstaSlideshow/releases).
2. Run `InstaSlideshowInstall.msi` and follow the setup wizard.
3. After installation, locate `InstaSlideshow.exe.config` in the install directory (usually `C:\Program Files\InstaSlideshow\`).

### Option B — build from source

1. Clone the repository:

   ```bash
   git clone https://github.com/mzbrau/InstaSlideshow.git
   ```

2. Open `InstaSlideshow.sln` in **Visual Studio 2019** or later.
3. Restore NuGet packages (Visual Studio does this automatically on first build).
4. Build the solution in **Release** configuration.
5. The output is in `InstaSlideshow\bin\Release\`.

---

## Configuration

Before launching, you must edit the application configuration file.

- **Installer build:** `C:\Program Files\InstaSlideshow\InstaSlideshow.exe.config`
- **Source build:** `InstaSlideshow\bin\Release\InstaSlideshow.exe.config`  
  (or edit `InstaSlideshow\App.config` before building)

Open the file in any text editor and fill in the `<appSettings>` section:

```xml
<appSettings>
  <!-- Display heading, e.g. your event hashtag -->
  <add key="HeadingText" value="#MyConference2025"/>

  <!-- The hashtag to search (without the # prefix) -->
  <add key="Hashtag" value="MyConference2025"/>

  <!-- Your Instagram username -->
  <add key="Username" value="your_instagram_username"/>

  <!-- Your Instagram password -->
  <add key="Password" value="your_instagram_password"/>

  <!-- Milliseconds each photo is displayed (default: 8000 = 8 s) -->
  <add key="TransitionSpeedMs" value="8000"/>

  <!-- Number of result pages to fetch per refresh cycle -->
  <add key="PagesCount" value="5"/>

  <!-- Oldest post date to show (MM/DD/YYYY) -->
  <add key="StartDate" value="01/01/2025"/>
</appSettings>
```

See the [Configuration Reference](./configuration) for a detailed description of every setting.

---

## Running the application

1. If running from a protected install directory (e.g. `C:\Program Files\`), right-click `InstaSlideshow.exe` and choose **Run as administrator**; otherwise double-click to launch normally.
2. The application authenticates with Instagram — this may take a few seconds.
3. Once logged in, the slideshow starts automatically in full-screen mode.

### Controls

| Action | Gesture / Key |
|---|---|
| Exit the application | Press **Escape** or **Alt + F4** |
| Move the window | Click and drag anywhere on the screen |

:::tip First-run state caching
On a successful login, InstaSlideshow saves a session state file (`state.bin`) next to the executable. Subsequent launches reuse this state, avoiding a full re-authentication.
:::

---

## Verifying everything works

After a few seconds you should see:

- Your **HeadingText** displayed at the top of the screen.
- An Instagram photo centred on a black background.
- The **poster's name** shown in the bottom-right corner.
- Photos cycling automatically every `TransitionSpeedMs` milliseconds.

If anything goes wrong, check the log file generated by NLog — see [Troubleshooting](./troubleshooting).
